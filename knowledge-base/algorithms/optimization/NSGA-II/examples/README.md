# NSGA-II 示例

以下示例可用于展示 NSGA-II 在多目标优化问题中的基本用法。

## 示例 1：两个目标的连续优化问题

- 问题 1：最小化 f1(x) = x^2
- 问题 2：最小化 f2(x) = (x-2)^2
- 变量范围：[-5, 5]

## 示例 2：经典 ZDT1 问题

- 目标 1：f1(x) = x1
- 目标 2：f2(x) = g(x) \* (1 - sqrt(x1 / g(x)))
- 适合用于验证 NSGA-II 的 Pareto 前沿质量。

## 示例 3：多目标工程调度

- 目标 1：最小化总完成时间
- 目标 2：最小化总能耗
- 变量：任务顺序、时间分配、功率级别

## 说明

这些示例用于帮助 LLM 理解 NSGA-II 的输入与输出格式、目标函数构造、搜索边界定义以及 Pareto 解集的多样性要求。
