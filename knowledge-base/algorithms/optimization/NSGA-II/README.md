# NSGA-II

NSGA-II（Non-dominated Sorting Genetic Algorithm II）是经典的多目标演化算法之一，适用于连续变量的多目标优化问题。

## 核心思想

- 使用快非支配排序（Fast Non-dominated Sorting）将种群按 Pareto 前沿分层。
- 对每一层计算拥挤距离（Crowding Distance），用于衡量解的多样性。
- 采用精英策略：父代与子代合并后进行环境选择，保证最优解不会丢失。
- 通过二元锦标赛（Binary Tournament）结合拥挤比较算子进行选择。
- 通常使用 SBX（Simulated Binary Crossover）和多项式变异（Polynomial Mutation）作为变异算子。

## 适用场景

- 连续决策变量问题
- 多目标优化问题，例如工程设计、调度、路径规划、能量管理
- 需要兼顾收敛性与多样性的场景

## 与 `python_multialg4` 的关系

`python_multialg4` 目前以单目标连续优化为主，整个框架采用 `MultiMet` 与算法 mixin 的设计模式。
NSGA-II 可以作为一个多目标扩展模块，引入以下关键部分：

- 问题接口支持返回目标向量而不是单值标量
- 快非支配排序与拥挤距离计算函数
- 精英式父子代合并与环境选择
- 基于多目标比较的二元锦标赛选择

如果把 NSGA-II 纳入该知识库，它更像是一个与现有单目标算法并行的多目标算法分支，适合用于构建算法知识 RAG 的多目标部分。

## 关键步骤

1. 初始化种群：生成连续变量个体。
2. 多目标评估：计算每个个体的目标向量。
3. 快非支配排序：将个体划分为第一层、第二层等。
4. 拥挤距离计算：为每个前沿内的个体计算多样性度量。
5. 选择操作：基于拥挤比较算子选择父代。
6. 交叉与变异：生成子代。
7. 合并选择：父代与子代合并后按非支配等级和拥挤距离截断至固定种群规模。

## 主要优势

- 非支配排序与拥挤距离结合，兼顾收敛性和多样性。
- 精英策略避免较好个体退化。
- 算法结构清晰，易于扩展到约束、多目标层次和偏好优化。
