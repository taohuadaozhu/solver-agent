# A-n32-k5 Capacitated Vehicle Routing Dataset

A-n32-k5 is a capacitated vehicle routing problem (CVRP) benchmark instance with 32 customers and 5 vehicles.
It is useful for testing route planning and vehicle capacity constraints in logistics optimization.

The raw instance file is located at `algorithm/MOEA_permutaition/data/A-n32-k5.vrp`.
