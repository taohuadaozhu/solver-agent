# Job Shop Scheduling Datasets

This folder contains the FT10 and FT20 job shop scheduling benchmark datasets.
FT10 and FT20 are classic JSP instances widely used to evaluate scheduling algorithms on small to medium-sized production planning problems.

Raw instance files are located at `algorithm/MOEA_permutaition/data/ft10.txt` and `algorithm/MOEA_permutaition/data/ft20.txt`.
